# #317 wait-shape qualification

This package implements only the result-independent first step of
[Issue #322](https://github.com/lisbun/lisjong-arena/issues/322).

## Ownership boundary

Canonical structural wait and wait-mechanism semantics remain owned by lisjong:

```text
lisjong.belief.exact_wait_ground_truth.exact_hand_belief_with_waits()
```

Arena adds only the bounded Stage-M0 projection:

```text
canonical Level-2 mechanism truth
  -> TANKI / SHANPON / KANCHAN / PENCHAN / RYANMEN
  -> KOKUSHI descriptive channel
```

RYANMEN is the logical OR of the canonical low-side and high-side channels.
The projection is multi-label. KOKUSHI-only is valid: all five ordinary shape
labels may be zero while the descriptive KOKUSHI channel is one.

## #258 reuse

The existing `stage_a0_tenpai_feasibility` package remains unchanged.
Its `RIICHI_EXCLUDED` meaning is still the non-riichi Tenpai target boundary.

#322 reuses the same-state hidden snapshot, public/private binding, physical
inventory checks, stable 13-equivalent checks, and retained sidecar payload.
It does not reinterpret the #258 Tenpai label.

## Pre-result lock

`wait_shape_qualification.protocol` freezes:

- current Heuristic Champion source and exact lisjong revision;
- `RiichiState.ACCEPTED` as the public-riichi eligibility state;
- pilot seeds 2000..2095 (96 hanchan);
- F1/F2 support thresholds;
- fresh scientific TRAIN / SELECT / EVAL populations;
- A/M, probe, and offline-EVAL result-independent constants;
- `DEFENSE DIAGNOSTIC NOT APPLICABLE`, because current lisjong analysis
  contracts expose defensive branch information but not an unambiguous
  current-teacher defense-action-change counterfactual suitable for a hard gate.

The qualification pilot is not generated by this change.
A/M training and interactive evaluation are also out of scope.
